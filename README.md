# KART STREET

Videojuego de carreras de karts desarrollado en Unity.

## Características
- Dos circuitos: Pista Pix y Pista Boscosa.
- Diferentes vehículos seleccionables.
- Sistema de vueltas y cronómetro.
- Integración con Supabase en desarrollo.

## Versiones
- ALFA: versión más reciente del proyecto.
- Versión 5: disponible en el historial de Git.
- Versiones 1 a 4: disponibles en GitHub Releases.
